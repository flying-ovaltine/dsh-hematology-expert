# 02 · 骨髓象判读

## 一、报告的六个必读项

拿到一份骨髓报告，只认这六行，其他描述都是补充：

1. **增生程度**（几分之几 / 分级）
2. **粒红比（G:E）**
3. **各系比例与形态**（红系、粒系、淋巴、单核、浆细胞、巨核）
4. **原始细胞百分比**（占全部有核细胞，还是占非红系 NEC——必须问清）
5. **病态造血**（有/无，哪一系，占多少）
6. **特殊染色与结论**（铁染色、PAS、MPO、网状纤维）

## 二、增生程度

常用五级法（以低倍镜下细胞与脂肪空泡比例粗估）：

| 分级 | 含义 | 常见于 |
|---|---|---|
| 极度减低 | 造血细胞 <10%（一片脂肪） | 重型再障 |
| 减低 | ~20%–30% | 再障、低增生 MDS、化疗后、骨髓浸润、结核 |
| 活跃 | ~50% | 正常、部分 ITP |
| 明显活跃 | 60%–70% | 溶血、缺铁、ITP、MPN、白血病 |
| 极度活跃 | >80%（"塞满"） | 急性白血病、CML、骨髓瘤、骨髓纤维化早期 |

**"增生减低"不等于再障。** 再障的骨髓特点是：增生减低＋粒红巨三系均减少＋非造血细胞（淋巴、浆细胞、网状细胞、脂肪细胞）比例相对升高＋无病态造血＋无原始细胞增多。**再障是排除诊断**：必须排除低增生 MDS、低增生 AML、PNH、淋巴瘤浸润、药物/毒物、结核、厌食症、酒精。

## 三、粒红比与各系

- **G:E 正常 2–4:1**。比值升高 → 粒系增多或红系减少（纯红再障、肾性贫血、慢性病）；比值降低/倒置 → 红系增生活跃（溶血、失血恢复、无效造血）或粒系减少。
- **红系**：正常约 20%–25%（有核红细胞占全部有核细胞）。增高见于溶血、失血、地贫、MDS；降低见于纯红再障、肾性贫血、慢性病贫血、化疗后。
- **粒系**：原始粒细胞 <5%；原粒＋早幼粒 <10%（不同实验室略有差异，以报告单标注为准）。
- **淋巴系**：成人 10%–20%；>20% 且形态异常需警惕淋巴瘤浸润、CLL 骨髓受累、ALL。
- **浆细胞**：正常 <2%（多数实验室可接受 <5%）。>10% 或成簇/成片分布 → 骨髓瘤方向；5%–10% 需结合 M 蛋白、游离轻链、影像、CRAB/SLiM 事件判断（MGUS 与 SMM 的分界）。
- **巨核系**：每张切片 7–35 个。增多见于 ITP、ET、PMF 早期；减少见于再障、化疗后。**要描述形态**：分叶是否正常、有无小巨核/单圆核巨核（MDS 特征）。

## 四、原始细胞计数：三个坑

1. **计数基数**：原始细胞百分比通常按"全部有核细胞"计，但 AML 诊断常按"非红系细胞（NEC）"计。红系增生明显时两者差异可达数个百分点，可能正好跨过 20% 或 10% 的门槛——**必须看报告写的是哪一个**。
2. **阈值因体系而异**：WHO 第5版 / ICC 2022 把 10%–19% 归入 MDS（MDS with increased blasts-2）；旧标准与部分临床试验仍用 ≥20% 定义 AML。**说结论时标明用哪套。**
3. **定义性遗传学异常不论比例**：t(15;17)/PML::RARA、t(8;21)/RUNX1::RUNX1T1、inv(16)/CBFB::MYH11、KMT2A 重排、NUP98 重排、DEK::NUP214 等，原始细胞不足 20% 也可诊断相应 AML 类型。APL 尤其如此——**形态＋凝血异常就该先上 ATRA**。

## 五、病态造血（dysplasia）

判定口径：**任一系中 ≥10% 的细胞存在该系病态形态**（WHO 口径）即算该系病态造血。

| 系 | 形态表现 |
|---|---|
| 红系 | 核出芽、多核、核碎裂、巨幼样变、环形铁粒幼、胞浆空泡、PAS 阳性 |
| 粒系 | 颗粒减少或无颗粒、Pelger-Huët 样（双叶核）、核分叶过少、染色质异常凝集、成熟停滞 |
| 巨核系 | 小巨核细胞、单圆核/多圆核巨核、分叶不良、颗粒缺失 |

注意：病态造血**不是** MDS 专属。B12/叶酸缺乏、酒精、HIV、药物（甲氨蝶呤、羟基脲、AZA、G-CSF 后）、中毒、先天性病态造血（如先天性角化不良）都能造成。**先排可逆原因，再谈 MDS。**

## 六、铁染色

- **细胞外铁**（巨噬细胞含铁血黄素）：半定量 0～+6。
- **铁粒幼细胞**（含铁小粒的红系前体）：正常 20%–90%。
- **环形铁粒幼细胞**（核周 ≥5 个铁粒环绕 ≥1/3 核周）：≥15% 有诊断意义（MDS-RS）；**SF3B1 突变者 ≥5% 即可**。
- 铁染色全阴＋细胞外铁 0 → 缺铁；铁 ↑ 但铁粒幼 ↓ → 慢性病贫血/炎症性；铁 ↑↑＋环形铁粒幼 → 铁粒幼细胞贫血/MDS-RS。

## 七、骨髓纤维化与干抽

- 网状纤维染色分级 **MF-0 ～ MF-3**；出现胶原纤维（三色染色阳性）即 MF-3。
- **干抽**（反复抽不出骨髓液）要想到：骨髓纤维化、骨髓"塞满"（急性白血病、MM、毛细胞白血病）、骨硬化、骨髓坏死、转移癌。干抽时**必须做骨髓活检**，涂片结论不可靠。
- 活检还能回答涂片答不了的问题：整体增生度、灶性浸润（淋巴瘤、转移癌、肉芽肿）、纤维化分级、AL 淀粉样变（刚果红）、再生障碍的"脂肪髓"范围。

## 八、常见结论模式速查

| 骨髓表现 | 首先考虑 |
|---|---|
| 增生减低＋三系减少＋非造血细胞增多＋无病态 | 再障 |
| 增生减低＋原始细胞 5%–19%＋病态造血 | 低增生 MDS |
| 增生活跃＋原始细胞 ≥20%（或有定义性遗传学异常） | AML |
| 原始细胞 10%–19%＋病态造血 | MDS-IB2 |
| 单系病态＋环形铁粒幼 ≥15% | MDS-RS（查 SF3B1） |
| 浆细胞 ≥10% 或成片＋CRAB/SLiM | 多发性骨髓瘤 |
| 浆细胞 <10%＋无事件 | MGUS（<10% 且 M 蛋白<30 g/L） |
| 粒系极度增生＋各阶段可见＋嗜碱增多＋小巨核 | CML（查 BCR::ABL1） |
| 巨核成簇＋核"云朵状"＋粒红增生 | PMF/ET/PV（查 JAK2/CALR/MPL） |
| 红系增多＋巨核正常＋粒系减少（纯红再障） | PRCA（查细小病毒 B19、胸腺瘤、药物） |
| 见成片形态单一的小淋巴细胞 | 淋巴瘤骨髓浸润/CLL |
| 见非造血细胞团块（腺样排列） | 转移癌 |
| 见到利什曼原虫/组织胞浆菌 | 感染性骨髓病变 |
| 见到戈谢细胞/尼曼匹克细胞 | 脂质储积病 |
| 骨髓坏死（细胞轮廓模糊、嗜酸性背景） | 白血病、淋巴瘤、感染、DIC、肿瘤 |
