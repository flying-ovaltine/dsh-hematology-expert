# 04 · 免疫组化与遗传/分子

## 一、淋巴瘤免疫组化：先分清"系别"，再分"亚型"

**第一步：系别归属（pan-B / pan-T / 其他）**

| 抗体 | 意义 |
|---|---|
| CD20 | B 细胞（浆细胞与部分浆母细胞阴性） |
| CD79a / PAX5 | B 细胞（PAX5 在霍奇金 R-S 细胞弱阳） |
| CD3 / CD5 / CD7 | T 细胞（CD5 亦见于 MCL、CLL） |
| CD30 | 霍奇金、间变大细胞淋巴瘤、部分 DLBCL |
| CD15 | 霍奇金（与 CD30 共表达、CD45 阴性） |
| CD45（LCA） | 造血细胞通用；霍奇金 R-S 细胞阴性是经典 |
| CD138 / MUM1 | 浆细胞分化 |
| CD56 / CD57 | NK、神经内分泌、部分 T 细胞 |
| EBER（原位杂交） | EBV 感染细胞（EBV+ DLBCL、NK/T、霍奇金、移植后淋巴增殖性疾病） |
| Ki-67 | 增殖指数（Burkitt ≈100%、侵袭性淋巴瘤高、惰性低） |

**第二步：DLBCL 的细胞起源（Hans 算法）**

```
CD10 阳性                        → GCB 型
CD10 阴性 + BCL6 阴性            → non-GCB 型
CD10 阴性 + BCL6 阳性 + MUM1 阴性 → GCB 型
CD10 阴性 + BCL6 阳性 + MUM1 阳性 → non-GCB 型
```
（Hans 用 IHC 近似，基因表达谱才是金标准；临床分层时说明这一点。）

**第三步：必须额外看的几个"危险标志"**

- **MYC 与 BCL2 双表达**：IHC 阈值常用 MYC ≥40%、BCL2 ≥50%（各中心略有差异）。双表达提示预后偏差，但**不等于双打击**。
- **双打击/三打击**：必须是 **FISH 证实 MYC 重排 + BCL2 和/或 BCL6 重排**。IHC 不能替代 FISH。
- **p53**：IHC 过表达（常用 ≥50% 强阳）或"完全缺失"都提示 TP53 异常，需 NGS 确认；与化疗耐药、预后差相关。
- **CD5 / CD10 / BCL6 / MUM1 / Cyclin D1 / SOX11 / LEF1 / LMO2 / MYD88**：用于 CLL 与 MCL、FL 与 MZL 等的鉴别。
- **PD-L1**：部分 DLBCL、原发纵隔大 B、霍奇金有表达，与免疫治疗选择相关（适应证以获批为准）。

**第四步：其他常见亚型的关键组合**

| 亚型 | 关键表型 |
|---|---|
| 经典型霍奇金 | CD30+ CD15+ CD20− CD45− PAX5 弱+ EBER± |
| 结节性淋巴细胞为主型霍奇金 | CD20+ CD45+ CD30− CD15− PD-1+（背景 T 细胞花环） |
| Burkitt | CD20+ CD10+ BCL6+ BCL2− Ki-67≈100% MYC 重排+ |
| 套细胞 | CD5+ Cyclin D1+ SOX11+（惰性型可 SOX11−） |
| 滤泡性 | CD10+ BCL2+ BCL6+ CD5−（Ⅰ级中心母细胞少） |
| 边缘区（结外/结内/脾） | CD20+ CD5− CD10− BCL2+，无特异标志，排除诊断 |
| 淋巴浆细胞淋巴瘤 | CD20+ CD138−/散在+ IgM+，MYD88 L265P 90%+ |
| 浆母细胞淋巴瘤 | CD138+ MUM1+ CD20−/弱 CD45−/弱 Ki-67 高 EBER±（HIV 相关常见） |
| 原发纵隔大 B | CD20+ CD23+ CD30 弱+ MAL+/CD30/PD-L1 高，常见 9p24.1 扩增 |
| 外周 T（非特指） | CD3+ CD4 为主，CD5/CD7 常缺失，TCR 克隆性 |
| 结外 NK/T | CD56+ CD3ε+（表面 CD3−）EBER+ 细胞毒颗粒+ |
| 间变大细胞（ALK+/−） | CD30 强阳、ALK±、细胞毒标志+ |

## 二、浆细胞与骨髓瘤的免疫组化

- **CD138、MUM1、CD38**：确认浆细胞。
- **CD56**：异常浆细胞常阳（正常浆细胞阴性），阴性者预后可能更差（更易浆细胞白血病化/髓外）。
- **Cyclin D1**：t(11;14) 提示（也见于 MCL，需结合 CD20/CD5）。
- **κ/λ 轻链**：**轻链限制是克隆性的直接证据**，比"浆细胞增多"重要。
- **CD20**：少数 MM 表达，与 t(11;14) 相关。
- **p53 IHC**：过表达提示 del(17p)/TP53 突变，高危。
- **刚果红**：怀疑 AL 淀粉样变时必做（苹果绿双折射）。

## 三、髓系与骨髓衰竭相关免疫组化

| 抗体 | 用途 |
|---|---|
| MPO | 髓系（AML 关键） |
| CD34 / CD117 | 原始细胞/干祖细胞 |
| CD61 / CD41 / 因子 VIII | 巨核系（小巨核、异常巨核） |
| CD68（KP1/PGM1）/ CD163 | 单核-巨噬系（CMML、组织细胞病） |
| 溶菌酶 | 髓系/组织细胞 |
| CD1a / langerin / S100 / BRAF V600E | 朗格汉斯细胞组织细胞增生症 |
| CD3 / CD20 / CD79a | 判断骨髓内淋巴浸润的系别 |
| 网状纤维（银染）/ 三色染色 | 骨髓纤维化分级（MF-0～3）、胶原化 |
| 血管密度（CD34/CD31） | 骨髓增殖性肿瘤评估（补充） |

## 四、遗传学：先看核型，再看 FISH，最后 NGS

**核型（G 显带，20 个中期分裂相）**
- 回答"整体染色体有没有丢、有没有易位、克隆大小"。
- 常见：t(15;17)、t(8;21)、inv(16)/t(16;16)、t(9;22)、复杂核型（≥3 个异常）、单体核型（≥2 个常染色体单体或 1 个单体+结构异常）、−5/5q−、−7/7q−、+8、del(20q)、del(17p)。
- **核型失败或干抽时 FISH 顶上**，但 FISH 只查探针覆盖的区域。

**FISH panel（按需）**
- AML/MDS：−5/5q−、−7/7q−、+8、del(20q)、del(17p)/TP53、11q23(KMT2A)、RUNX1::RUNX1T1、CBFB::MYH11、PML::RARA、NUP98 等。
- ALL：BCR::ABL1、KMT2A 重排、ETV6::RUNX1、TCF3::PBX1、iAMP21、IKZF1 缺失、Ph 样。
- 淋巴瘤：MYC、BCL2、BCL6（双/三打击判定必用）；MCL 的 t(11;14)；FL 的 t(14;18)；MALT 的 t(11;18)/t(14;18)/t(3;14)。
- MM：del(17p)、t(4;14)、t(14;16)、t(11;14)、1q21 扩增（**≥4 拷贝为高危**；3 拷贝为"gain"）。

**NGS / 靶向测序**
- AML：NPM1、FLT3-ITD/TKD、CEBPA（bZIP）、RUNX1、ASXL1、TP53、KMT2A-PTD、IDH1/2、DNMT3A、SRSF2、U2AF1、STAG2、WT1。
- MDS/MPN：SF3B1（环形铁粒幼＋预后较好）、TET2、SRSF2、ASXL1、DNMT3A、JAK2/CALR/MPL、CSF3R、SETBP1、EZH2、IDH1/2、U2AF1、TP53（双等位失活→极差）。
- CLL：TP53、del(11q)/ATM、NOTCH1、SF3B1、BIRC3、IGHV 突变状态（≥2% 为突变型，预后好）。
- MM：TP53、RAS（KRAS/NRAS/BRAF）、t(11;14)（BCL2 抑制剂敏感）、1q21、DIS3、ATM。
- 淋巴瘤：MYD88 L265P（LPL/WM、部分 DLBCL）、CXCR4（WM）、EZH2/IDH2（FL）、NOTCH1/2（CLL、T-ALL）、TP53、CD79B（DLBCL 的 BTKi 敏感性）。
- 遗传易感：家族性血液肿瘤、年轻患者、多原发肿瘤时考虑 germline 检测（UKCGG 2025 有路径建议）。

## 五、看遗传学报告的四个注意

1. **克隆大小**：FISH 报的"阳性细胞比例"有阈值（常用 5%–10%），低于阈值可能被判"阴性"，但低比例克隆在随访中有意义。
2. **定义性 vs 预后性**：t(15;17) 是定义性（决定诊断和用药）；del(17p) 是预后性（决定分层与方案选择）。别混着说。
3. **外周血 vs 骨髓**：CLL 的 FISH 用外周血即可；MM 的遗传学必须骨髓（且浆细胞比例低时需 CD138 磁珠分选提高检出率）。
4. **NGS 报的 VAF**：VAF 低不等于不重要（如 TP53 在 MDS 中的小克隆同样提示不良），但要注意区分体细胞与胚系（VAF≈50% 时要怀疑胚系）。
