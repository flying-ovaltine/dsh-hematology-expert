# 01 · 血常规与外周血涂片

## 二、贫血的三向分流（这一步决定后面查什么）

**第 1 刀：网织红（ARC）**
- ARC 升高（RPI>2）→ 生成没问题，问题在**丢得多或破得多**：失血、溶血。
- ARC 降低或不升（RPI<2）→ **生成不足**：营养、骨髓衰竭、慢性病、肾性、内分泌。

**第 2 刀：MCV（在"生成不足"分支里）**

| MCV | 首查 | 关键鉴别 |
|---|---|---|
| <80 小细胞 | 铁蛋白、TSAT、TIBC、CRP | IDA（铁蛋白↓）、慢性病贫血（铁蛋白正常/↑、TSAT↓）、地中海贫血（MCV↓而 RDW 多正常、Mentzer 指数<13、靶形红细胞）、铁粒幼细胞贫血（环形铁粒幼） |
| 80–100 正细胞 | 肾功、CRP/ESR、甲功、肝功能、EPO | 肾性贫血、慢性病贫血、内分泌、骨髓衰竭（AA/MDS/浸润）、纯红细胞再生障碍 |
| >100 大细胞 | B12、叶酸、TSH、肝功、酒精史、网织红 | 巨幼细胞贫血（B12/叶酸↓、中性粒核分叶过多）、MDS（大细胞＋病态造血、B12/叶酸正常）、酒精/肝病、药物（羟基脲、甲氨蝶呤、AZA）、甲减 |

**溶血分支（ARC↑）必查组合**：间接胆红素、LDH、结合珠蛋白、网织红、外周血涂片、直接抗人球蛋白试验（Coombs）、CD55/CD59 或 FLAER（PNH）、G6PD 活性（避开溶血发作期）、血红蛋白电泳（地贫）、腹部超声（脾大）。

## 三、白细胞异常的走向

- **中性粒细胞增多**：感染（细菌）、应激、激素、G-CSF、吸烟、骨髓增殖性肿瘤。伴左移＋嗜碱增多＋脾大 → 先想 CML（查 BCR::ABL1）。
- **中性粒细胞减少**：药物（最常被忽略，包括抗甲状腺药、抗生素、抗癫痫药、硫唑嘌呤）、病毒、自身免疫、脾亢、MDS、AA、周期性粒缺。**ANC<0.5 为粒细胞缺乏，<0.1 为极重度**。
- **淋巴细胞绝对值升高**：>5×10⁹/L 持续 3 个月是 CLL 的诊断门槛（单克隆 B 淋巴细胞≥5×10⁹/L）；5 以下但持续升高需查克隆性（流式 κ/λ 限制）。传染性单核细胞增多症、CMV、百日咳、应激也可升高。
- **单核细胞增多**：>1×10⁹/L 持续 → 查 CMML（需单核≥0.5×10⁹/L＋骨髓病态＋克隆性）、结核、肿瘤、结缔组织病。**全血细胞减少伴单核细胞明显减少**要想到毛细胞白血病。
- **嗜酸粒细胞增多**：绝对值>1.5×10⁹/L 称高嗜酸粒细胞血症，需查寄生虫、过敏、药物、EGPA、以及克隆性（FIP1L1::PDGFRA、PDGFRB、FGFR1、JAK2）。
- **嗜碱粒细胞增多**：CML 的经典线索，也见于 MPN、过敏、甲减。

## 四、血小板

- **减少**：先排假性（EDTA 依赖、聚集、巨大血小板漏计）。真性减少按"生成↓ / 破坏↑ / 分布异常"分：骨髓生成看骨髓报告；破坏看脾大、TTP/HUS、DIC、药物、感染、免疫（ITP 为排除诊断）；分布异常看脾亢、低温。
- **增多**：>450×10⁹/L 为血小板增多。反应性（感染、缺铁、术后、脾切除、肿瘤）远多于 ET；ET 需 JAK2/CALR/MPL＋骨髓形态＋排除其他 MPN。
- **功能异常**：数量正常仍出血 → 查 vWD、血小板功能试验、尿毒症、药物（阿司匹林、氯吡格雷、替罗非班）。

## 五、涂片形态词表（看到什么意味着什么）

**红细胞**
- 大小不均＋低色素（中心淡染区>1/3）→ IDA、地贫
- 球形红细胞（>10% 有意义）→ 遗传性球形红细胞增多症、AIHA
- 裂红细胞（盔形、三角形）→ TMA（TTP/HUS/DIC）、机械性（瓣膜、ECMO）、恶性高血压、HELLP
- 泪滴细胞 → 骨髓纤维化、骨髓浸润
- 靶形红细胞 → 地贫、肝病、脾切除后、HbC/E
- 嗜多色性 → 网织红增多（溶血/失血恢复期）
- 有核红细胞 → 溶血、髓外造血、骨髓浸润、缺氧
- 缗钱状排列 → 多发性骨髓瘤/巨球蛋白血症（需与标本久置鉴别）
- 红细胞凝集 → 冷凝集素病
- 豪-乔小体（Howell-Jolly）→ 脾功能低下、溶血、MDS

**白细胞**
- **Auer 小体** → 髓系，AML（APL 最常见）；见到即支持 AML，不必等 20%
- 原始细胞形态：核浆比大、染色质细致、核仁明显 1–3 个、胞浆少而嗜碱
- 中毒颗粒、Döhle 体、空泡 → 严重感染/炎症
- **Pelger-Huët 样异常（双叶核"眼镜状"）** → MDS 病态造血的经典形态；也见于药物、遗传性
- 中性粒细胞核分叶过多（≥6 叶）→ 巨幼细胞贫血
- **涂抹细胞（smudge cell）** → CLL 的标志性背景
- 毛细胞（胞浆毛发样突起）→ 毛细胞白血病
- 花瓣样核/多形核淋巴细胞 → 成人T细胞白血病/淋巴瘤（ATLL），查 HTLV-1
- 大颗粒淋巴细胞增多 → T-LGLL（需流式 TCR 克隆性）
- 异常浆细胞（双核、火焰细胞、Mott 细胞）→ 浆细胞肿瘤

**血小板**
- 大血小板/巨血小板 → 生成旺盛（ITP）、MYH9 相关病、Bernard-Soulier
- 血小板卫星现象 → 假性减少

## 六、几组"一眼组合"

| 组合 | 首先想 |
|---|---|
| 全血细胞减少＋网织红↓＋脾不大＋MCV 正常偏高 | 再障 / 低增生 MDS / PNH |
| 全血细胞减少＋大细胞＋核分叶过多 | 巨幼细胞贫血 |
| 全血细胞减少＋单核明显减少＋脾大 | 毛细胞白血病 |
| 贫血＋血小板减少＋肾损害＋神经症状＋裂红细胞 | TTP（急症） |
| 贫血＋黄疸＋网织红↑＋脾大 | 溶血性贫血 |
| 白细胞显著增高＋嗜碱增多＋脾大 | CML |
| 淋巴细胞升高＋涂抹细胞 | CLL |
| 贫血＋血小板减少＋球蛋白升高＋骨痛＋肾功异常 | 多发性骨髓瘤 |
| 嗜酸增多＋心肌/皮肤/神经受累 | 高嗜酸粒细胞综合征（查 FIP1L1::PDGFRA） |
